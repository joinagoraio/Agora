# Agora User Guide

## Welcome to Agora

Agora is a collaborative platform for managing documents, conducting research, and working with AI-powered assistance.

---

## Getting Started

### Creating an Account

1. Visit the sign-up page
2. Enter your email and password
3. Verify your email address
4. Complete your profile

### Logging In

1. Go to the login page
2. Enter your email and password
3. Click "Sign In"

---

## Workspaces

### Creating a Workspace

1. Click "New Workspace" or "+" button
2. Enter workspace name and description
3. Select parent space (if applicable)
4. Click "Create"

### Workspace Features

- **Documents** - Upload and manage documents
- **Chat** - Ask questions about your documents
- **Notes** - Take notes and collaborate
- **Evidence** - Save evidence and citations
- **Settings** - Configure workspace settings

---

## Documents

### Uploading Documents

1. Go to your workspace
2. Click "Upload Document"
3. Select file (PDF, Word, or text)
4. Choose classification (Public, Internal, Confidential)
5. Add title (optional)
6. Click "Upload"

**Supported Formats:**
- PDF (.pdf)
- Microsoft Word (.docx)
- Plain Text (.txt)
- Markdown (.md)

**File Size Limit:** 50MB

### Viewing Documents

1. Click on a document in the list
2. View in the document viewer
3. Navigate pages (for PDFs)
4. Use search within document

### Document Classification

- **Public** - Visible to all workspace members
- **Internal** - Visible to workspace members only
- **Confidential** - Restricted access

---

## Chat with AI

### Asking Questions

1. Open the chat panel
2. Type your question
3. Press Enter or click Send
4. View AI response with citations

### Features

- **Context-Aware** - AI understands your workspace context
- **Citations** - Responses include source references
- **Highlights** - Click citations to see highlighted text
- **Conversation History** - Previous conversations are saved

### Tips

- Be specific in your questions
- Reference document names when helpful
- Ask follow-up questions
- Use the chat for research and analysis

---

## Search

### Basic Search

1. Use the search bar
2. Enter your query
3. View results with filters

### Advanced Search

Use filters to narrow results:
- **Domain** - Filter by domain/topic
- **Municipality** - Filter by location
- **Year** - Filter by publication year
- **Classification** - Filter by document type
- **Layer** - Filter by government layer

### Search Tips

- Use quotes for exact phrases
- Combine multiple filters
- Save frequent searches
- Use pagination for large result sets

---

## Collaboration

### Sharing Workspaces

1. Go to workspace settings
2. Click "Share"
3. Generate share link
4. Send link to collaborators

### Permissions

- **Viewer** - Can view documents
- **Contributor** - Can add documents
- **Analyst** - Can analyze and annotate
- **Project Owner** - Full access
- **Org Manager** - Organization management

---

## Spaces

### Understanding Spaces

Spaces are organizations or tenants that contain workspaces. They provide:
- **Organization Settings** - Configure organization details
- **Member Management** - Invite and manage members
- **Publishable Items** - Share items across workspaces

### Space Types

- **National** - National government
- **Regional** - Regional government
- **Municipal** - Municipal government
- **Party** - Political party
- **Other** - Other organizations

## Troubleshooting

### Common Issues

**Can't upload document:**
- Check file size (max 50MB)
- Verify file format is supported
- Check your permissions

**Chat not responding:**
- Check your internet connection
- Wait a moment and try again
- Refresh the page if needed

**Can't find document:**
- Check search filters
- Verify workspace access
- Check document classification

### Getting Help

- Check this documentation
- Contact support
- Report bugs via feedback
